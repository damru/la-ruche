# Internationalisation (i18n)

## Frontend

- Every user-visible string goes through vue-i18n (`frontend/src/locales/`). No raw text in templates.
- Keys are named by feature/epic (e.g. `ag.resolution.title`), never source text as key.

## Backend

- The backend never returns a displayable hard-coded error message: it returns stable error codes under the `errors.*` namespace, translated on the frontend via vue-i18n.
- Any new error code must have a translation in every locale.

## Local formats

- Dates, numbers and amounts are formatted with `Intl` using the `fr-FR` locale by default (the application is French).
- Amounts are stored as integer cents in the backend, formatted on the frontend.
