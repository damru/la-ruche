# Internationalisation (i18n)

## Frontend

- Toute chaîne visible par l'utilisateur passe par vue-i18n (`frontend/src/locales/`). Pas de texte brut dans les templates.
- Clés nommées par fonctionnalité/épic (ex. `ag.resolution.title`), pas de texte source comme clé.

## Backend

- Le backend ne renvoie jamais de message d'erreur affichable en dur : il renvoie des codes d'erreur stables sous l'espace `errors.*`, traduits côté frontend via vue-i18n.
- Un code d'erreur nouveau doit avoir sa traduction dans toutes les locales.

## Formats locaux

- Dates, nombres et montants formatés via `Intl` avec la locale `fr-FR` par défaut (l'application est en français).
- Les montants sont stockés en centimes (entiers) côté backend, formatés côté frontend.
