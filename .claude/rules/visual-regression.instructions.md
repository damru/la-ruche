# Visual regression captures (Phase 3)

- `frontend/e2e/visual/*.png` are **CI-generated artifacts committed to the repo** — the before/after diff appears natively in the PR Files Changed tab (GitHub Swipe view). Never regenerate, retouch or delete them manually.
- Filenames are deterministic: `<page-slug>--<viewport>--<theme>.png`. They come from `e2e/tests/visual/pages-capture.spec.ts` — change the matrix there, not the files.
- The captures job pushes PNG commits as `github-actions[bot]` in a separate `chore(visual)` commit; code and captures are never mixed in one commit. That push happens only after every other job is green, so CI skips it: a head commit touching ONLY `frontend/e2e/visual/` sets `captures_only` in the `changes` job and every substantive job (docker included) is skipped — no approval gate, no loop.
- New stable layout page (main layout) → add it to `e2e/data/access-matrix.ts`; it is captured automatically (first allowed account, 1440 + 375, light + dark).
- Captures run on CI x86 ONLY — never run the `visual` Playwright project locally (ARM64 rendering differs; local PNGs would poison the baselines).
- Captures are **fullPage** (`scrollHeight` and `scrollWidth` — horizontal overflow shows as a wider capture, e.g. tables at 375 px). Sticky/fixed elements are painted at their scroll-0 position by Chromium's `captureBeyondViewport` — the bottom nav (product: `fixed`; sticky overlays content at scroll 0 and fails axe target-size) is rendered `position: static` + `order: 3` during capture (see the addStyleTag in `pages-capture.spec.ts`) so it paints once, at its natural end-of-page spot.
- Determinism is non-negotiable: fixed clock and forced theme live in the capture spec; if a page starts rendering relative dates, counters or random IDs, freeze them rather than accepting churny diffs.
- Unchanged page → identical PNG → no diff in the PR. If an unrelated PR shows visual churn, hunt the determinism leak first, not the screenshot.
- The capture pipeline discards only diffs pixelmatch counts as 0 px (byte-level PNG noise); any visible-or-near-visible change is kept for review (user policy: prefer false positives over missed changes). Identical-run jitter is 0 px since fonts are self-hosted via fontsource — the Google-Fonts CDN served varying variable-font instances and caused 8-616 px diffs. Never load fonts from a CDN: any external font source reintroduces capture churn.
